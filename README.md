# DashCord site

Marketing site for DashCord (Arabic, RTL). React + Vite + TypeScript.

- Live: https://dashcord-hq.github.io/dashcord-site/
- Source: `dashcord-site-source.zip` (full project: `src/`, `package.json`, `vite.config.ts`). Unzip, then `npm install`, `npm run dev` or `npm run build`.
- Font: IBM Plex Sans Arabic (bundled, weights 400-700).
- Demo request form: `src/DemoForm.tsx`, set `SIGNUP_ENDPOINT` once the backend exists (see spec).
- WhatsApp widget and contact numbers: `src/config.ts`.
